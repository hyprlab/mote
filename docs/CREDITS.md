# Credits

Mote is maintained by [Hyprlab](https://github.com/hyprlab). This page says
what each contributor's work was; the names alone live in
[`data/TRANSLATORS`](../data/TRANSLATORS), which is what the app's About
window shows. Want to join them? See [CONTRIBUTING.md](CONTRIBUTING.md).

## Translations

Every language Mote speaks was given to it by somebody:

- **French:** [frenchy82](https://github.com/frenchy82)
  ([#1](https://github.com/hyprlab/mote/pull/1)), Mote's first translation
- **Italian:** [mrCabez](https://github.com/mrCabez)
  ([#4](https://github.com/hyprlab/mote/pull/4))

Adding or updating one is the easiest way in: see [po/README.md](../po/README.md).
